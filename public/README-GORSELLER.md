# public/ klasörüne koymanız gerekenler

Yönetim paneli bu dosyaları arar. Yoksa arayüz çalışır ama logo yerine
kırık görsel simgesi çıkar.

| Dosya | Nerede kullanılır | Öneri |
|---|---|---|
| `cocuktribunu.png` | Giriş ekranı (açık tema) | 512×512, şeffaf arka plan |
| `cocuktribunud.png` | Kenar çubuğu, giriş (koyu tema) | 512×512, şeffaf arka plan |
| `favicon.ico` | Tarayıcı sekmesi | 32×32 |
| `favicon.png` | PWA ikonu | 512×512 |

Ana sitedeki (`cocuk-tribunu/public/`) dosyaların aynısını buraya kopyalayabilirsiniz.

> Bu dosyaları eklemeden de deploy edebilirsiniz; panel çalışır.
